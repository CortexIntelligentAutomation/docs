{{% pageinfo %}}
This guide describes how to install the AI model server that the {{% ctx %}} Documentation Service uses to write flow documentation, and how to create and configure the Documentation Service. The Documentation Service, and the AI application that it runs in, are installed with {{% ctx %}} but are not created by default. It always runs on the Web Application Server. The AI model server can be installed on the Web Application Server, or on a separate Model Server if the Web Application Server cannot provide the resources. See [Choose Where to Install the AI Model Server](choose-installation) to decide where to install it.
